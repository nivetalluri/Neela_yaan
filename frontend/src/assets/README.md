# Reference coastline
`world-land.json` is Natural Earth's 1:110m land GeoJSON, public-domain cartographic data.

License/terms: https://www.naturalearthdata.com/about/terms-of-use/
Used as an offline fallback under the live tile layer, NOT as a nautical navigation chart.
